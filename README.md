# Quiz Game — семейная викторина для ПК

Desktop‑приложение на Python + PySide6 для проведения семейных и дружеских квизов на большом экране (телевизор, проектор).  
С ноутбука запускается админ‑панель, которая управляет списком команд и их очками, а на втором экране отображается только красивый «big screen» с таблицей лидеров.

## Основные возможности

- Управление командами
  - Добавление и удаление команд из админ‑панели
  - Изменение очков через контекстное меню (+1, +5, −1, −5)
  - Автоматическая сортировка по количеству очков
- Большой экран
  - Отдельное окно для показа на телевизоре/проекторе
  - Крупные строки с командами и очками, читаемые издалека
  - Медали и эмодзи для первых мест, «клоун» для последнего
  - Фоновое изображение и лёгкий снежный эффект
- История событий
  - Лог всех действий: добавление/удаление команд, изменение очков
  - Просмотр истории прямо в админ‑панели
- Темы
  - Светлая и тёмная тема (переключаются одной кнопкой)
- Обновления
  - Кнопка «Проверить обновление» сравнивает текущую версию с последним релизом на GitHub и при желании открывает страницу релиза

## Установка и запуск из исходников

1. Установите Python 3.10+.
2. Клонируйте репозиторий:
git clone https://github.com/DexMP/quiz_game.git
cd quiz_game

3. Установите зависимости:
pip install -r requirements.txt

4. Запустите приложение:
python main.py


## Использование

1. **Запуск админ‑панели.**  
После запуска появляется окно `Quiz Admin — Aurora Light`.

2. **Добавление команд.**  
Нажмите «Добавить команду» и введите название. Команды появляются в таблице слева.

3. **Изменение очков.**  
- Клик правой кнопкой по команде в таблице.  
- Выберите в контекстном меню нужное действие: `+1`, `+5`, `−1`, `−5`.

4. **Показ большого экрана.**  
- Нажмите кнопку «Показать большой экран».  
- Выберите монитор (телевизор/проектор).  
- Окно big screen развернётся на выбранный экран во весь экран.

5. **Смена темы.**  
Кнопка «Тёмная тема» переключает оформление между светлой и тёмной темой.

6. **Сохранение и загрузка состояния.**  
- Кнопка «Сохранить» — сохраняет команды, очки, тему и историю в `quiz_state.json`.  
- Кнопка «Загрузить» — загружает состояние из выбранного `.json`‑файла.

## Готовый exe (Windows)

Для удобства есть сборки под Windows в разделе [Releases](https://github.com/DexMP/quiz_game/releases).  
Скачайте последний `quiz_game.exe`, запустите и пользуйтесь без установки Python.
