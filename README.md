# Quiz Game — семейная викторина для ПК

> **Desktop-приложение на Python + PySide6** для проведения семейных и дружеских квизов на большом экране (телевизор, проектор).

🎮 С ноутбука запускается **админ-панель**, которая управляет списком команд и их очками, а на втором экране отображается красивый **big screen** с таблицей лидеров и привлекательной визуализацией.

---

## ✨ Основные возможности

### 👥 Управление командами
- ➕ Добавление и удаление команд из админ-панели
- 🎯 Изменение очков через контекстное меню (+1, +5, −1, −5)
- 📊 Автоматическая сортировка по количеству очков (в реальном времени)
- 💾 Сохранение и загрузка состояния игры в JSON

### 🖥️ Большой экран
- 📺 Отдельное окно для показа на телевизоре/проекторе (полноэкранный режим)
- 📈 Крупные строки с командами и очками, читаемые издалека
- 🏅 **Медали** для первых мест (🥇 🥈 🥉)
- 🤡 Забавный эмодзи для последнего места
- 🎉 **Падающее конфетти** для создания праздничной атмосферы
- 🖼️ Кастомное фоновое изображение
- ⚡ **Оптимизированная производительность** (низкая нагрузка на CPU)

### 📝 История событий
- 📋 Лог всех действий: добавление/удаление команд, изменение очков
- 👁️ Просмотр истории прямо в админ-панели

### 🎨 Темы и оформление
- ☀️ **Светлая тема** (Aurora Light Pro) — стильный дизайн по умолчанию
- 🌙 **Тёмная тема** (Aurora Dark) — для удобства в тёмных помещениях
- ⚡ Переключение одной кнопкой

### 🔄 Обновления
- 🔍 Кнопка «Проверить обновление» сравнивает текущую версию с последним релизом на GitHub
- 📖 При наличии обновления показывает информацию и предлагает открыть страницу релиза в браузере
- 🔔 Визуальный индикатор доступного обновления

## 🚀 Установка и запуск

### Из исходников (требуется Python)

**Требования:** Python 3.10+

```bash
# Клонируем репозиторий
git clone https://github.com/DexMP/quiz_game.git
cd quiz_game

# Устанавливаем зависимости
pip install -r requirements.txt

# Запускаем приложение
python main.py
```

### Готовый exe для Windows

🎁 **Для удобства** — скачайте готовую сборку из раздела [Releases](https://github.com/DexMP/quiz_game/releases):

```
1. Перейти в Releases
2. Скачать latest quiz_game.exe
3. Запустить (Python не требуется!)
```

## 📖 Использование

### 1️⃣ Запуск админ-панели
- Запустите `python main.py` или откройте `quiz_game.exe`
- Появляется окно **Quiz Admin** с красивым оформлением

### 2️⃣ Добавление команд
- Нажмите кнопку **«Добавить команду»**
- Введите название команды
- Команда появляется в таблице слева с очками 0

### 3️⃣ Изменение очков
- **Клик правой кнопкой** по строке команды в таблице
- В контекстном меню выберите:
  - **+1** — добавить 1 очко
  - **+5** — добавить 5 очков
  - **−1** — вычесть 1 очко
  - **−5** — вычесть 5 очков

### 4️⃣ Показ большого экрана
- Нажмите кнопку **«Показать большой экран»**
- Выберите монитор (телевизор/проектор)
- Окно big screen развернётся во весь экран на выбранном мониторе
- Таблица автоматически обновляется при изменении очков

### 5️⃣ Смена темы
- Переключатель **«Тёмная тема»** меняет оформление между светлой и тёмной темой
- Выбор сохраняется при загрузке состояния

### 6️⃣ Сохранение и загрузка
- **Кнопка «Сохранить»** — сохраняет команды, очки, тему и историю в `quiz_state.json`
- **Кнопка «Загрузить»** — восстанавливает сохранённое состояние из `.json`-файла

### 7️⃣ Проверка обновлений
- Нажмите **«Проверить обновление»**
- При наличии новой версии откроется диалог с информацией
- Нажмите «Да» чтобы открыть страницу релиза в браузере
